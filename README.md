# Simulador de distribuciones de probabilidad

## Requisitos
- Python 3.10 o superior
- pip

## Instalación
```bash
pip install -r requirements.txt
```

## Ejecución
```bash
streamlit run app.py
```
## O en su defecto
```bash
python -m streamlit run app.py
```

## Distribuciones implementadas
- Binomial
- Poisson
- Geométrica
- Normal
- Uniforme continua
- Exponencial

## Funcionalidades
- Selección de distribución.
- Entrada y validación de parámetros.
- Tamaño de muestra configurable.
- Generación de datos aleatorios.
- Cálculo de media, varianza y desviación estándar.
- Gráficas comparativas entre simulación y modelo teórico.
- Tabla comparativa entre valores teóricos y simulados.
- Interpretación estadística automática.
- Exportación de resultados en CSV.
